VANTA is our flagship: eight independent voices, each with two oscillators, a resonant ladder filter, and its own small amount of tuning and envelope error, because a perfectly matched voice card has never existed.

Unison stacks all eight. The modulation matrix has twenty-four slots and no hidden routing. It is the instrument the playable demo on this site actually runs — not a marketing mock-up of it, not a recording of it, the same signal path compiled for the browser.

Signal flow

One path, drawn honestly

Per voice: two oscillators and a sub into the mixer, then the filter, then the amplifier. Drive, delay and reverb sit on the shared bus after the voices sum. The LFO reaches pitch, cutoff and amplitude directly.

Per-voice stages are drawn once. Everything to the left of DRIVE exists eight times over; everything from DRIVE onward is shared.

Inside VANTA

What eight voices actually costs

Architecture, modulation, and the parts we refused to fake.

01 / Eight real voices

Eight real voices

Eight voices, two oscillators each, allocated round-robin with proper release stealing. A held chord keeps its tails when the ninth note arrives.

02 / Two filters, one path

Two filters, one path

A four-pole ladder with self-oscillation and a state-variable filter with continuous LP–BP–HP morph. Series or parallel, with a single blend control.

03 / Per-voice analog error

Per-voice analog error

Each voice carries independent tuning, envelope-timing and filter-cutoff offsets. One knob scales the whole spread from dead-accurate to visibly falling apart.

04 / 24-slot modulation matrix

24-slot modulation matrix

Every source reaches every destination at audio rate. Slots are listed, not buried: source, destination, depth, curve, four columns, no submenus.

05 / MPE and plain MIDI

MPE and plain MIDI

Full MPE with per-note pitch, pressure and slide, and a legacy mode that maps the same destinations to mod wheel and aftertouch for ordinary keyboards.

06 / Presets you can read

Presets you can read

Presets are plain text, tagged and diffable, stored in a folder you choose. Copy one into a chat window and it still loads on the other end.

Questions

Before you spend $149

If the answer you need is not here, the documentation goes considerably deeper, and it was written by the people who wrote the code.

Is the browser demo the real instrument?

It is the same signal path — two oscillators and a sub per voice, the same filter topology, the same envelope shapes, the same effects order — compiled to run in a tab. What the browser cannot give it is the plugin's oversampling, its full voice count under load, and sample-accurate host timing. Treat the demo as an honest audition, not a measurement.

Do I need an account or an iLok to try it?

No. The browser demo needs nothing at all. The installable demo is the full plugin with saving disabled; it does not phone home and it does not create an account. Licensing is a file you download once.

How many machines does one licence cover?

Three, active at the same time, in any combination of platforms. Authorisation is offline — you copy a licence file into the plugin's folder and VANTA never checks anything at load time. The licence is transferable: you can sell it on, once, and we will move it for you.

What does “free 1.x updates” actually mean?

Every release numbered 1.anything is included, for as long as the 1.x line is maintained. That covers 1.4.0, which you are looking at, and everything after it in that line. If there is ever a VANTA 2, it will be a separate purchase and existing owners will be offered an upgrade price, not a subscription.

Will my presets survive an update?

Yes. The preset format is plain text and has been stable since 1.0; new parameters take their default value when an older preset is loaded, and the file is rewritten only when you save it. Presets live in a folder you pick, not inside the plugin bundle, so an uninstall cannot take them with it.

Which hosts do you test against?

Every release is tested in the hosts listed under system requirements in the documentation, on all three platforms, in every format we ship. When a host changes something that breaks us, we say so in the changelog and name the host.

Is there a CPU cost I should plan for?

A plain eight-voice patch is cheap. The two things that cost real cycles are an eight-voice unison stack and a self-oscillating ladder with a high cutoff. The numbers we measure are in the System & CPU tab above; they are measured, not estimated, and they are per core.

The licence, in plain language

You buy a copy of the software. You keep it.

  • You may install VANTA on as many machines as you own and have three authorised at once. Swapping the third for a fourth takes about ten seconds and needs no email.
  • Authorisation is a file. It is checked when you drop it in, never when the plugin loads, and never over the network. A studio with no internet connection is a supported configuration, not an edge case.
  • Sessions you have already rendered keep working whatever happens to us. The preset format is plain text specifically so that nothing you make is trapped.
  • You may transfer the licence to another person once, at no cost, by telling us the name it should move to.
  • You may not redistribute the installer or the licence file, and you may not use the factory presets as the basis of a preset pack you sell.
