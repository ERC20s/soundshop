The format

Presets you can read

Presets are plain text, tagged and diffable, stored in a folder you choose. Copy one into a chat window and it still loads on the other end.

One object per preset

A name, an author, a category, a handful of tags and a flat map of parameter values. No binary blobs, no database, nothing that needs the plugin open to inspect.

Parameter names are the API

The keys under params are the same identifiers the plugin automates and the browser engine reads. What you copy from this page is what the instrument loads.

Partial presets are legal

Leave a key out and that control keeps its current value. It is how a “filter only” or “effects only” preset is written, and it survives a copy-paste through anything.
